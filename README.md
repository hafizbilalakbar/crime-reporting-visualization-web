## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/hafizbilalakbar/crime-reporting-visualization-web.git
cd crime-reporting-visualization-web

# Install dependencies
npm install

```

## 💻 Usage

### Development
```bash
# Start development server
Open index.html in browser
```

### Build for Production
```bash
# Create production build
npm run build
```

### Start Production Server
```bash
# Run production build
npm run start
```
